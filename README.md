# Analisis-Geospasial
Peta sebaran penyakit Puskesmas Lubuk Buaya Kota Padang pada September 2026 menunjukkan distribusi enam kelompok penyakit di setiap kelurahan. Hipertensi menjadi penyakit tertinggi (12,2%), diikuti ISPA (9,5%). Informasi ini membantu menentukan wilayah prioritas serta mendukung upaya pencegahan dan peningkatan pelayanan kesehatan.
